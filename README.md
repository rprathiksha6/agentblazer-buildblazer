# AgentBlazer Club & Build Blazer Platform — Phase 2

Official web platform for **AgentBlazer Club**, Department of Computer Science & Engineering, St Joseph Engineering College (SJEC), Mangaluru.

Pioneering Autonomous & Agentic AI Systems, collaborative workshops, Salesforce Trailblazer community synergy, and the **Build Blazer Phase 2** live build sprint.

---

## ⚡ Features & Modules

- **Creative Cyberpunk Aesthetic**: Dynamic multi-theme switching (`⚡ Violet`, `🔥 Inferno`, `❄️ Frost`), cyber-grid particles, glowing holographic badge, and glassmorphic cards.
- **Student & Admin Portals**:
  - **Student View**: Explore club charter, faculty council, student core team, past/upcoming activities, submit Phase 2 projects, and ask doubts.
  - **Admin Portal**: Organizer console protected by passcode (`agentblazer2026` or one-click organizer access) to review doubts, publish replies, grade team submissions, broadcast live notifications, and export data.
- **BlazerBot AI Assistant**: Floating side chatbot with interactive question selector chips (e.g. *"What is AgentBlazer?"*, *"Who runs the club?"*, *"What is Build Blazer?"*, *"How to submit project?"*, *"How to ask a doubt?"*, *"Upcoming activities?"*) plus smart keyword query search.
- **Ask Doubt Desk**: Dedicated section where students enter their credentials (Name, USN, College Email, Department, Year, Query Category) to submit doubts directly into the club's backend with instant ticket ID generation and live public doubts tracker.
- **Build Blazer Phase 2 Submission Desk**: Interactive form for teams to log Team Name, Team Lead, Members, Figma Reference Link, GitHub Fork URL, Live Deployed Website Link, and Tech Stack.
- **Foundations & Leadership**: Comprehensive documentation of the Club Launch & Agentforce Symposium (August 25, 2025), honored guests, Faculty Advisory Council, and Student Core Team.
- **Interactive Media Wall**: Mosaic collage of campus hackathons, symposium keynotes, and laboratory sessions.
- **Real-time Notifications**: Broadcast drawer for students with live alerts dispatched from the Admin Portal.

## 🚀 Getting Started

### 1. Prerequisites
- **Node.js** (v18 or newer recommended)
- **npm** (v9 or newer)

### 2. Installation
```bash
git clone https://github.com/AgentBlazer/agentblazer-buildblazer.git
cd agentblazer-buildblazer
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
The app will run locally at `http://localhost:3000`.

### 4. Build for Production
```bash
npm run build
```
The production bundle is compiled into the `dist/` directory, ready to deploy to Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
